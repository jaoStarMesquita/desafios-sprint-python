# Desafios Sprint — Desenvolvimento em Python

Repositório acadêmico destinado à organização dos entregáveis da disciplina de Desenvolvimento em Python.

## Sprints

- **Sprint 1:** Fundamentos de Python
- **Sprint 2:** Estruturas condicionais e repetição
- **Sprint 3:** Funções e modularização
- **Sprint 4:** Estruturas de dados
- **Sprint 5:** Sistema de análise de dados
- **Sprint 6:** Programação Orientada a Objetos

## Tecnologias

- Python 3
- Git e GitHub

## Objetivo

Organizar os exercícios e projetos desenvolvidos ao longo das Sprints, documentar os requisitos de cada atividade e acompanhar a evolução dos conhecimentos em programação.

Os códigos e documentos serão adicionados e atualizados conforme o desenvolvimento de cada entrega.
