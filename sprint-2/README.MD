# Sprint 2 — Estruturas de Controle em Python

## Objetivo

Aplicar estruturas condicionais e de repetição para desenvolver programas capazes de tomar decisões, processar conjuntos de números e controlar tentativas de acesso.

## Desafios

1. **Classificador de clientes:** classifica clientes de acordo com as condições definidas no exercício, utilizando `if`, `elif` e `else`.
2. **Menu de operações matemáticas:** apresenta opções de operações e executa a operação escolhida pelo usuário.
3. **Análise de números:** recebe cinco números e calcula a soma, a média, o maior e o menor valor.
4. **Sistema de autenticação:** solicita uma senha e controla o número máximo de tentativas.

## Conceitos praticados

- Estruturas condicionais: `if`, `elif` e `else`.
- Seleção de opções com `match/case`.
- Laços de repetição com `for` e `while`.
- Contadores e acumuladores.
- Comparações e operadores lógicos.
- Validação de entradas.
- Controle de tentativas de autenticação.
- Formatação de resultados com f-strings.

## Como executar

Execute cada desafio Python individualmente, a partir da raiz do repositório:

```bash
python sprint-2/python/classificador_cliente.py
```

Para testar os demais desafios, substitua o nome do arquivo pelo correspondente.

## Objetivo de aprendizagem

Compreender como utilizar condições e repetições para controlar o fluxo de execução de um programa, além de implementar soluções equivalentes em Portugol.
