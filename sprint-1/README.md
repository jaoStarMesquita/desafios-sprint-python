# Sprint 1 — Fundamentos de Python

## Objetivo

Praticar os fundamentos da programação em Python por meio de seis desafios, trabalhando entrada de dados, operações matemáticas, variáveis, conversão de tipos e estruturas condicionais.

## Desafios

1. **Calculadora de troco:** calcula o troco de uma compra com base no valor pago e no preço.
2. **Média de notas:** recebe três notas e calcula a média do aluno.
3. **Conversor de tempo:** converte valores de tempo entre unidades.
4. **Calculadora de desconto:** calcula o desconto e o preço final de um produto.
5. **Par ou ímpar:** identifica se um número inteiro é par ou ímpar.
6. **Inversor de nome:** recebe um nome e exibe os caracteres em ordem inversa.

## Conceitos praticados

- Variáveis e tipos de dados.
- Entrada de dados com `input()`.
- Conversão de tipos com `int()` e `float()`.
- Operações aritméticas.
- Saída de dados com `print()`.
- Formatação de texto com f-strings.
- Estruturas condicionais com `if` e `else`.
- Manipulação de strings.

## Como executar

Com o Python 3 instalado, abra o terminal na raiz do repositório e execute o arquivo correspondente aos desafios:

```bash
python sprint-1/01_calculadora_troco.py
```

## Objetivo de aprendizagem

Desenvolver a lógica de programação e compreender como receber, processar e apresentar dados em Python.
